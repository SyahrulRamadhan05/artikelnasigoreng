# Jurnal Bersepeda Nusantara

Website sederhana berupa blog informatif seputar dunia bersepeda. Proyek ini dibuat sebagai **Tugas Akhir (Submission)** untuk menyelesaikan kelas [Belajar Dasar Pemrograman Web](https://www.dicoding.com/academies/123) di **Dicoding Academy**.

## Deskripsi Proyek

Website ini berisi artikel edukasi tentang jenis-jenis sepeda (Mountain Bike, Road Bike, Folding Bike) dan tips aman bersepeda di jalan raya. Tampilan website dirancang menggunakan pendekatan layout yang modern dan responsif agar tetap rapi dan nyaman dibaca, baik melalui layar desktop maupun layar *smartphone*.

## Kriteria Pemrograman & Fitur

Proyek ini dibangun murni dari nol tanpa menggunakan *framework* atau *library* CSS eksternal (seperti Bootstrap atau Tailwind), guna membuktikan pemahaman dasar pemrograman web dan memenuhi standar *reviewer* Dicoding:
- **Semantic HTML5:** Memanfaatkan struktur tag semantik yang tepat, seperti `<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, dan `<footer>`.
- **CSS Flexbox:** Tata letak (*layouting*) disusun murni menggunakan teknik *Flexbox* (tidak menggunakan *float*).
- **Responsive Web Design:** Menggunakan *Media Query* pada CSS untuk memastikan tampilan menyesuaikan ukuran perangkat.
- **Pemisahan Berkas:** Kode *styling* dipisahkan secara rapi ke dalam berkas `.css` mandiri.

## Cara Menjalankan Secara Lokal

Karena proyek ini hanya terdiri dari HTML dan CSS statis, Anda tidak memerlukan instalasi *local server* (seperti XAMPP atau Node.js).
1. Unduh (*Download ZIP*) atau *clone repository* ini.
2. Ekstrak (jika berbentuk ZIP), lalu buka folder proyek.
3. Klik ganda (*double click*) pada file `index.html`.
4. Website akan langsung terbuka di browser utama Anda.
